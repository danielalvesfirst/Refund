## 🇺🇸 English / 🇬🇧 English

### About

**Refund** is a web application for registering and tracking expense reimbursement requests.

Users can add expenses by providing the expense name, category, and amount. Added expenses are displayed in a list, while the application automatically updates the number of expenses and the total amount. Individual expenses can also be removed.

### Features

* Add new expenses
* Select an expense category
* Automatic Brazilian Real (BRL) currency formatting
* Display registered expenses
* Automatic expense counter
* Automatic total calculation
* Remove individual expenses
* Responsive layout

### Categories

Expenses can be classified as:

* 🍔 Food
* 🏨 Accommodation
* 🛠️ Services
* 🚗 Transportation
* 📦 Others

* JavaScript

* Currency formatting

### Running the project

Clone the repository:

```bash
git clone https://github.com/danielalvesfirst/Refund.git
```

Enter the project folder:

```bash
cd Refund
```

Then open `index.html` in your browser.

You can also use **Live Server** in VS Code for local development.

## 🇧🇷 Português / 🇵🇹 Português

### Sobre

**Refund** é uma aplicação web para registrar e acompanhar solicitações de reembolso de despesas.

O usuário pode adicionar uma despesa informando seu nome, categoria e valor. As despesas adicionadas aparecem em uma lista, enquanto a aplicação atualiza automaticamente a quantidade de despesas e o valor total. Também é possível remover cada despesa individualmente.

### Funcionalidades

* Adicionar novas despesas
* Selecionar a categoria da despesa
* Formatação automática dos valores em reais (BRL)
* Exibição das despesas cadastradas
* Contagem automática de despesas
* Cálculo automático do valor total
* Remoção individual de despesas
* Layout responsivo

### Categorias

As despesas podem ser classificadas como:

* 🍔 Alimentação
* 🏨 Hospedagem
* 🛠️ Serviços
* 🚗 Transporte
* 📦 Outros

### Tecnologias

* Eventos em JavaScript
